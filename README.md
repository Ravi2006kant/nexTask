# NexTask App 📋

A simple and intuitive task management application built with **Flutter** that helps users organize their daily activities, manage tasks, and stay productive.

## 📱 About the Project

Next Task App is a Flutter-based to-do list application designed to make everyday task management easier. Users can create, manage, and track their tasks through a clean and user-friendly interface.

The goal of this project was to build a practical application while strengthening my understanding of Flutter development and application functionality.

## ✨ Features

- Add new tasks.
- View and manage your task list.
- Edit existing tasks.
- Delete tasks.
- Mark tasks as completed.
- Simple and user-friendly interface.

## 📥 Download & Installation

### Option 1: Download the Android App

1. Visit the https://github.com/Ravi2006kant/nexTask/releases/tag/v1.0.0
2. Download the APK file.
3. Open the downloaded APK on your Android device.
4. Allow installation from unknown sources if Android asks.
5. Install the application and start managing your tasks!

### Option 2: Run the Project Locally

**Prerequisites:**
- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Git

**Step 1: Clone the repository**

```bash
git clone https://github.com/Ravi2006kant/nexTask.git
```

**Step 2: Navigate to the project directory**

```bash
cd nextask
```

**Step 3: Install dependencies**

```bash
flutter pub get
```

**Step 4: Run the application**

```bash
flutter run
```
